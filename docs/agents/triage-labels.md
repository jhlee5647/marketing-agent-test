# Triage 라벨

스킬들은 다섯 가지 표준 triage 역할로 말합니다. 이 파일은 그 역할을 이 저장소의 이슈 트래커에서 실제로 쓰는 라벨 문자열에 대응시킵니다.

| mattpocock/skills의 라벨 | 우리 트래커의 라벨 | 의미                                  |
| ------------------------ | ------------------ | ------------------------------------- |
| `needs-triage`           | `needs-triage`     | 메인테이너가 검토해야 하는 이슈       |
| `needs-info`             | `needs-info`       | 보고자에게 추가 정보를 기다리는 중    |
| `ready-for-agent`        | `ready-for-agent`  | 명세가 끝나 AFK 에이전트가 맡을 수 있음 |
| `ready-for-human`        | `ready-for-human`  | 사람이 구현해야 함                    |
| `wontfix`                | `wontfix`          | 처리하지 않음                         |

스킬이 역할을 언급하면(예: "AFK 준비 완료 triage 라벨을 붙인다") 이 표에서 해당하는 라벨 문자열을 씁니다.

실제로 쓰는 어휘가 다르면 오른쪽 열을 고칩니다.
